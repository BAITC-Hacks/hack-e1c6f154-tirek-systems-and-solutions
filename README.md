# hack-e1c6f154-tirek-systems-and-solutions
Hackathon team repository for Tirek Systems and Solutions

## Tirek: рекомендации по пополнению склада

Цель прототипа — быстро сформировать объяснимые рекомендации закупщику на основе
свежих данных, ML-прогноза и индивидуальной экономики каждого товара.
Менеджер проверяет рекомендации, корректирует их и утверждает экспорт заказа.

В первые 15 минут команды принимают или совместно корректируют контракт.
После этого платформа работает с синтетическими [примерами](contracts/examples/),
а бэкенд реализует тот же формат. Первый общий сценарий должен работать к T+90 мин.

**Текущее состояние:** в репозитории подготовлены ТЗ, контракт и примеры ответов.
Приложение, обучение модели и HTTP-эндпоинты ещё не реализованы.
Примеры являются синтетическими образцами контракта, а не результатами обучения.

Партнёрские Excel/PDF/ZIP, API-ключи и реальные данные клиентов в репозиторий не добавляем.
Порядок локального подключения данных указан в ТЗ бэкенда.

Проверка схемы и синтетических примеров описана в [contracts/README.md](contracts/README.md).
