# Работа с общим репозиторием

По просьбе Адильжана перед новой работой проверяйте `git status` и подтягивайте
обновления через `git pull --rebase`. Сохраняйте незакоммиченные изменения без потери;
не перезаписывайте работу других участников.

После завершения изменений запускайте относящиеся к ним проверки, создавайте коммит
и делайте `git push`. Если remote обновился, повторите pull с rebase, разрешите
конфликты с сохранением изменений команды и проверьте затронутые части перед push.
Не используйте force push. Партнёрские данные, секреты и локальные базы не коммитьте.

Для полного backend/ML используйте Python 3.12 и `backend/requirements-ml.txt`.
На Windows локальное окружение — `.venv-ml`. Браузерные тесты изменяют базу:
запускайте сервер для них с отдельным `DATA_DIR`, затем возвращайте рабочую базу.
