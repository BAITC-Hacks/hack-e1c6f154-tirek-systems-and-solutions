# Tirek frontend

React + TypeScript + Vite. Русский интерфейс, Manrope (шрифт поставляется локально), Phosphor, Recharts, Radix Dialog.

Из `frontend/`:

```powershell
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Backend должен работать на порту 8000; `/api` проксируется через Vite. Адрес другого API задаётся через `VITE_API_URL` в `frontend/.env.local` (полный базовый URL с `/api/v1`). При сетевой ошибке показывается ошибка, демо не включается автоматически.

## Экраны

- `/`: обзор, состояние запаса, история отдельного товара, очередь внимания.
- `/recommendations`: поиск, категории, срочность, отбор позиций, карточка и корректировка.
- `/data`: drag-and-drop XLSX, ограничения файлов, JSON-контекст, отчёт импорта.
- `/approvals`: утверждённые снимки и повторный экспорт.
- `/settings`: реальные возможности текущего бэкенда и ограничения демонстрации.

Типы API генерируются из общего `contracts/openapi.yaml`; бизнес-формулы закупки в браузере отсутствуют.

```powershell
npm run generate:types
npm run build
```

## Браузерные проверки

Запустить оба сервера, затем из `frontend/`:

```powershell
npx playwright install chromium --no-shell
npm run test:e2e
```

Используется полный Chromium (`channel: chromium`), без отдельного headless shell. Проверяются desktop/mobile, поиск и пустые значения, drawer и Escape, ошибка партии, корректировка, утверждение, фактическое скачивание CSV, сохранение истории и отсутствие подмены ошибок mock-данными. Тесты создают синтетические расчёты и снимки в активной локальной базе; для изоляции запустите сервер с отдельным `DATA_DIR`.

Скриншоты сохраняются в `test-results/`, в Git не входят.
