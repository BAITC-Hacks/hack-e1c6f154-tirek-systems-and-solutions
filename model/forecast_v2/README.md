# Прогноз наблюдаемых продаж, v2

Изолированный эксперимент для SE и IEK, горизонт 28 дней. Код, веса и агрегированные
результаты находятся в этом каталоге. Партнёрские XLSX, кэш и построчные прогнозы
хранятся отдельно от Git. Никаких UI, HTTP-сервисов или синтетического доказательства точности.

Подробные численные результаты и ограничения: [REPORT.md](REPORT.md).

## Воспроизведение

Из корня worktree. Ниже использован проверенный интерпретатор Python 3.12 этой машины;
на другой машине замените его своим Python 3.12:

```bash
/home/perricheno/Documents/Codex/2026-09-23/fdf/work/ml-runtime/bin/python -m venv /tmp/forecast-v2-venv
/tmp/forecast-v2-venv/bin/pip install -r model/forecast_v2/requirements.txt
PYTHON=/tmp/forecast-v2-venv/bin/python bash model/forecast_v2/reproduce.sh \
  '/home/perricheno/Documents/Codex/2026-09-23/fdf/work/inputs' \
  /tmp/forecast-v2-private \
  /tmp/forecast-v2-reproduced
```

Скрипт проверяет временные инварианты, выбирает метод по трём validation-окнам,
проверяет также фиксированную сетку выпуклых смесей двух методов,
сохраняет окончательные `selection.json` и SHA-256, выполняет ablation истории 2024 года,
повторно оценивает два ранее просмотренных окна, обучает финальные веса и проверяет
их загрузку через формирование прогноза. Последовательность нельзя менять ради
лучшего результата на evaluation. Сравнение моделей хранится целиком, включая проигравших. Для повторного обучения
выбирайте новый каталог `OUTPUT_DIR`: уже оценённый эксперимент защищён от перезаписи.

Для прогноза с сохранёнными весами:

```bash
/tmp/forecast-v2-venv/bin/python -m model.forecast_v2.run infer \
  --inputs '/home/perricheno/Documents/Codex/2026-09-23/fdf/work/inputs' \
  --output model/forecast_v2/artifacts \
  --private /tmp/forecast-v2-private \
  --cache /tmp/forecast-v2-private/cache.pkl \
  --predictions /tmp/forecast-v2-private/forecast.csv
```

По умолчанию origin — предпоследний день выгрузки, 21.09.2026: полнота 22.09 не
подтверждена. Для явного использования доступной части 22.09 можно передать
`--origin 2026-09-22`. Это не утверждение о полном дне. Прогноз начинается на
следующий день после origin. Загрузка финальных весов для более ранних дат запрещена:
исторические оценки требуют отдельного обучения на соответствующую дату.

CSV содержит поставщика, SKU, единицу, склад, origin, начало/конец горизонта,
тип продаж и ABC по прошлым наблюдениям, выбранный метод и его прогноз, лучший
ML-кандидат и baseline v1. Количества дробные; это точечные прогнозы, не заказы,
не MOQ и не гарантированные уровни обслуживания. Интервалы не заявляются.

Свежая выгрузка должна содержать полную совместимую историю с 2025 года и отдельную
помесячную историю 2024 года. Остатки, категории и клиенты не восстанавливаются.
Кэш pickle — только собственный локальный файл этого скрипта; чужие кэши не загружать.
При изменении входов или кода он пересоздаётся. XLSX никогда не перезаписываются.

## Артефакты

- `protocol.json` — даты, цель, критерий выбора и правила источников.
- `artifacts/selection.json`, `selection.lock.json` — выбор до evaluation и контрольная сумма.
- `artifacts/validation.json` — все кандидаты и три окна, аудит источников, группы, границы обучения.
- `artifacts/ablation.json` — те же кандидаты без 2024, только validation; выбор не меняется.
- `artifacts/evaluation.json` — ретроспективные результаты, группы, смещения, нулевые цели и неизвестные SKU.
- `artifacts/manifest.json`, `*.cbm` / файлы коэффициентов — реальные финальные веса и SHA-256.
- `artifacts/verification.json` — независимая сверка целей с XLSX, метрик, временных границ, весов и baseline v1.

WAPE = Σ|прогноз − продажи| / Σпродажи. MAE — средняя абсолютная ошибка на SKU × окно.
Смещение = Σ(прогноз − продажи) / Σпродажи; плюс означает завышение. Если знаменатель
нулевой, WAPE и относительное смещение `null`, абсолютная ошибка остаётся в отчёте.
Проценты окон не усредняются: объединяются числители и знаменатели. Метры, упаковки
и штуки не суммируются; общий показатель рассчитывается отдельно для каждой единицы.
